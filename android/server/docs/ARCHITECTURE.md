# Архітектура УкрЧату

## УкрЧат 1

Телефон користувача є локальним AI-сервером.

Схема:

Телефон → УкрЧат → локальний AI-сервер → llama.cpp → локальна GGUF-модель

## Запуск

AI-сервер автоматично запускається при відкритті УкрЧату.

## Вимкнення

Після закриття УкрЧату AI-сервер працює ще 2 хвилини,
після чого автоматично вимикається.

## Інтернет

Для роботи AI інтернет не потрібен.

Gemini API не використовується.
